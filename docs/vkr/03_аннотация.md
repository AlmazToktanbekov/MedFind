# АННОТАЦИЯ

В выпускной квалификационной работе спроектирована и разработана информационная система «MedFind» — медицинская платформа для поиска врачей, клиник и аптек в Кыргызской Республике, состоящая из кроссплатформенного мобильного приложения, серверной части и веб-панели администратора.

Объект исследования — процесс информационного взаимодействия пациентов с поставщиками медицинских услуг. Предмет исследования — методы и средства проектирования и разработки кроссплатформенного мобильного приложения с серверной частью. Цель работы — создание единой системы поиска медицинских услуг для Кыргызской Республики.

При разработке использованы: фреймворк Flutter (язык Dart) для мобильного приложения, фреймворк FastAPI (язык Python) для серверной части, система управления базами данных PostgreSQL. Применены объектно-ориентированное проектирование и моделирование на языке UML.

Результатом работы является готовое к внедрению специализированное программное решение, объединяющее каталоги врачей, клиник и аптек со средствами поиска, фильтрации и сравнения. Область применения — сфера здравоохранения Кыргызской Республики.

Пояснительная записка содержит около 50 страниц, 12 рисунков, 14 таблиц, 18 источников и 3 приложения. Графическая часть — 4 листа формата А1.

Ключевые слова: мобильное приложение, медицинская платформа, Flutter, FastAPI, PostgreSQL, поиск врачей, REST API.

**Аннотация (кыргыз тилинде)**

Бүтүрүүчү квалификациялык иште Кыргыз Республикасында дарыгерлерди, клиникаларды жана дарыканаларды издөө үчүн «MedFind» маалыматтык системасы — медициналык платформа долбоорлонуп, иштелип чыкты. Система кроссплатформалык мобилдик тиркемеден, сервердик бөлүктөн жана администратордун веб-панелинен турат.

Изилдөөнүн объекти — бейтаптардын медициналык кызмат көрсөтүүчүлөр менен маалыматтык өз ара аракеттенүү процесси. Иштин максаты — медициналык кызматтарды издөөнүн бирдиктүү системасын түзүү.

Иштеп чыгууда мобилдик тиркеме үчүн Flutter фреймворку (Dart тили), сервердик бөлүк үчүн FastAPI фреймворку (Python тили) жана PostgreSQL маалымат базаларын башкаруу системасы колдонулган.

Иштин жыйынтыгы — колдонууга даяр программалык чечим. Колдонуу чөйрөсү — Кыргыз Республикасынын саламаттыкты сактоо тармагы. Түшүндүрмө кат болжол менен 50 беттен, 12 сүрөттөн, 14 таблицадан, 18 булактан жана 3 тиркемеден турат.

Урунттуу сөздөр: мобилдик тиркеме, медициналык платформа, Flutter, FastAPI, PostgreSQL, дарыгерлерди издөө.

**Abstract**

This graduation qualification work presents the design and development of the «MedFind» information system — a medical platform for searching doctors, clinics and pharmacies in the Kyrgyz Republic, consisting of a cross-platform mobile application, a server side and a web-based administrator panel.

The object of research is the process of information interaction between patients and medical service providers. The aim of the work is to create a unified system for searching medical services in the Kyrgyz Republic.

The mobile application was developed using the Flutter framework (Dart language), the server side — using the FastAPI framework (Python language) and the PostgreSQL database management system. Object-oriented design and UML modelling were applied.

The result of the work is a software solution ready for deployment that combines catalogues of doctors, clinics and pharmacies with search, filtering and comparison tools. The field of application is the healthcare sector of the Kyrgyz Republic. The explanatory note contains approximately 50 pages, 12 figures, 14 tables, 18 references and 3 appendices.

Keywords: mobile application, medical platform, Flutter, FastAPI, PostgreSQL, doctor search, REST API.
