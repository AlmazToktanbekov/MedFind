# ПРИЛОЖЕНИЕ Б. Структура таблиц базы данных

В приложении приведён перечень таблиц реляционной базы данных системы «MedFind» с указанием их назначения.

| Таблица | Назначение |
|---|---|
| users | учётные записи пользователей всех ролей |
| otp_codes | одноразовые коды подтверждения |
| doctors | профили врачей |
| doctor_contacts | контакты врачей |
| doctor_services | услуги врачей |
| doctor_schedules | график приёма врачей |
| doctor_profile_updates | заявки врачей на изменение профиля |
| clinics | профили клиник |
| clinic_photos | фотогалереи клиник |
| pharmacy_companies | профили аптечных компаний |
| pharmacy_branches | филиалы аптечных компаний |
| pharmacy_branch_photos | фотогалереи филиалов аптек |
| reviews | отзывы на врачей, клиники и филиалы аптек |
| symptoms | каталог симптомов |
| symptom_specializations | связь симптомов со специализациями |
| favorites | избранные объекты пользователей |
| complaints | жалобы пользователей |
| notifications | уведомления пользователей |
| analytics_events | события для формирования аналитики |
| ai_conversations | история диалогов с AI-ассистентом |
| search_logs | журнал поисковых запросов |
| admin_logs | журнал действий администраторов |
| articles | служебная таблица справочных материалов |
