# ОБОЗНАЧЕНИЯ И СОКРАЩЕНИЯ

В настоящей пояснительной записке применяются следующие сокращения и обозначения:

| Сокращение | Расшифровка |
|---|---|
| API | программный интерфейс приложения (Application Programming Interface) |
| CORS | механизм управления доступом к ресурсам между разными источниками (Cross-Origin Resource Sharing) |
| FCM | служба доставки push-уведомлений (Firebase Cloud Messaging) |
| HTTP | протокол передачи гипертекста (HyperText Transfer Protocol) |
| JSON | текстовый формат обмена данными (JavaScript Object Notation) |
| JWT | стандарт маркеров доступа (JSON Web Token) |
| ORM | объектно-реляционное отображение (Object-Relational Mapping) |
| OTP | одноразовый код подтверждения (One-Time Password) |
| REST | архитектурный стиль программных интерфейсов (Representational State Transfer) |
| SMS | служба коротких сообщений (Short Message Service) |
| UML | унифицированный язык моделирования (Unified Modeling Language) |
| ВКР | выпускная квалификационная работа |
| ПО | программное обеспечение |
| СУБД | система управления базами данных |
