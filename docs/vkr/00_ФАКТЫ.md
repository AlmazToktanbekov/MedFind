## 1. Общее

- **Название:** MedFind — медицинская платформа Кыргызской Республики.
- **Назначение:** соединяет пациентов с врачами, клиниками и аптеками.
- **Состав системы (3 части):**
  1. **Backend** — REST API на FastAPI + PostgreSQL.
  2. **Mobile** — кроссплатформенное приложение на Flutter (iOS/Android).
  3. **Admin Panel** — веб-панель администратора на Jinja2, встроена в backend.
- **Тип ВКР:** A — прикладной проект (программно-серверное обеспечение).

## 3. Архитектура

### Общая
Трёхзвенная клиент-серверная архитектура:
- **Клиент** — мобильное приложение Flutter.
- **Сервер** — REST API FastAPI (бизнес-логика, аутентификация).
- **Хранилище** — PostgreSQL.
Дополнительно: веб-панель администратора (серверный рендеринг Jinja2), внешние сервисы (Mistral AI, Firebase FCM, SMS-шлюз Nikita.kg).

### Backend — слои
- `app/routers/` — обработчики HTTP-эндпоинтов (15 роутеров).
- `app/models/` — ORM-модели SQLAlchemy (22 таблицы).
- `app/schemas/` — Pydantic-схемы (отдельно на чтение и запись).
- `app/services/` — бизнес-сервисы (SMS, FCM, scheduler, аналитика, логи).
- `app/core/` — конфигурация, БД, безопасность, rate limiting.
- `app/templates/admin/` — Jinja2-шаблоны админ-панели.
- Паттерн: async-сессия БД через `Depends(get_db)`, eager loading через `selectinload`.

### Mobile — слои (Feature-first)
Каждая фича в `mobile/lib/features/<name>/`:
- `data/` — Repository: HTTP-запросы через `ApiClient().dio`.
- `providers/` — StateNotifierProvider: бизнес-логика и состояние.
- `presentation/screens/` — экраны (виджеты).
12 фич: `ai`, `analytics`, `auth`, `clinics`, `doctors`, `health`, `home`, `notifications`, `pharmacies`, `profile`, `provider`, `search`.

### Сеть
`ApiClient` — singleton, `baseUrl = http://localhost:8000`. JWT-интерцептор Dio: подставляет `Authorization: Bearer`, при 401 — автоматический рефреш токена через `/auth/refresh` с очередью повторных запросов.

## 5. Роли пользователей

| Роль | Значение в БД | Описание |
|---|---|---|
| Пациент | `patient` | основной пользователь |
| Врач | `doctor` | регистрируется через приложение, привязан к 1 клинике |
| Клиника | `clinic` | управляет своими врачами |
| Аптека | `pharmacy` | управляет компанией и филиалами |
| Администратор | `admin` | управляет платформой через веб-панель |

### Статусы врача
`pending` (ждёт подтверждения клиники) → `active` (виден пациентам) / `rejected` / `deactivated` / `removed` (удалён из клиники, не виден, в кабинете красная плашка). Публично отдаются только `active`.

### Статусы клиник/аптек
Регистрируются сами, **сразу активны** (без модерации админом). Может быть `is_frozen` (заморозка админом).

## 7. Безопасность (реализовано)

- **JWT**: access + refresh, алгоритм HS256, access живёт 7 дней; автоматический рефреш при 401.
- **Хеширование паролей** — bcrypt.
- **Защищённое хранение** токенов на устройстве — `flutter_secure_storage`.
- **Rate limiting** — slowapi (ограничение частоты запросов).
- **Security-заголовки** — middleware: X-Content-Type-Options, X-Frame-Options, Referrer-Policy, Permissions-Policy, HSTS (в проде).
- **Защита от перебора пароля** — `failed_login_attempts` + `locked_until` (блокировка аккаунта).
- **CORS** — белый список доменов в проде, `*` в DEV.
- **OTP** — код живёт 5 минут, ограничение попыток ввода.
- **DEV_MODE** — OTP возвращается в ответе без реальной отправки SMS.
- **Авто-блокировка по жалобам** — пороги 10/100/300, блок на 14 дней.

## 8. Ключевой функционал (реализовано)

- **Аутентификация:** регистрация по телефону + пароль, OTP-подтверждение, восстановление пароля, JWT.
- **Каталоги:** врачи, клиники, аптеки (компании + филиалы) с фильтрами.
- **Поиск:** глобальный поиск, поиск врачей по симптому, по специализации; лог запросов.
- **Кабинеты провайдеров:** пошаговая регистрация и управление для врача, клиники, аптеки.
- **Управление врачами клиникой:** подтверждение/отклонение/деактивация/удаление, модерация изменений профиля.
- **Отзывы и рейтинги:** на врачей, клиники, филиалы аптек.
- **Избранное:** синхронизируется с сервером.
- **AI-ассистент:** чат на Mistral AI с серверной историей.
- **Аналитика:** трекинг событий, отчёты для клиник и аптек с графиками (fl_chart).
- **Жалобы:** подача жалоб, авто-уведомления и авто-блокировки (APScheduler, 09:00 Asia/Bishkek).
- **Push-уведомления:** FCM + локальные + in-app.
- **Геолокация:** ближайшие аптеки (формула Haversine), маршруты (2GIS → Google Maps).
- **Локализация:** 3 языка — русский, кыргызский, английский.
- **Веб-панель администратора:** дашборд, управление пользователями/контентом, модерация жалоб, аудит.
